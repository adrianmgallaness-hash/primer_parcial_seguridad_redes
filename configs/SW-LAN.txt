Verified VLAN / port-security information
-----------------------------------------
The IOSvL2 `show running-config` output does not list the VLAN database entries, so these were verified separately during the lab:

VLAN 10  USERS
VLAN 20  ADMIN

Gi0/0 -> 802.1Q trunk, allowed VLANs 10,20
Gi0/1 -> access VLAN 10, port-security enabled, maximum 2 MAC addresses
Gi0/2 -> access VLAN 20, port-security enabled, maximum 2 MAC addresses

Port-security violation verified on Gi0/1:
- Violation Mode: Shutdown
- Port Status: Secure-shutdown
- Security Violation Count: 1
- Violating MAC: 0211.2233.4402
- Interface state observed: err-disabled

Note: `shutdown` is the default port-security violation action on this IOSv image, so it does not appear explicitly in `show running-config` even though it was configured and verified with `show port-security interface gi0/1`.
